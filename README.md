# GESSTION ESSTANDAR — sitio web

Prototipo responsive de una landing page corporativa para GESSTION ESSTANDAR.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: sistema visual responsive.
- `script.js`: menú móvil, animaciones y formulario demo.
- `assets/logo-ss.png`: isotipo suministrado por el usuario.

## Uso

Abrir `index.html` en un navegador moderno. No requiere dependencias externas.

## Antes de publicar

1. Conectar el formulario de contacto a un correo, CRM o endpoint real.
2. Añadir datos corporativos definitivos: correo, teléfono, dirección, redes y política de tratamiento de datos.
3. Revisar metadatos SEO y dominio canónico.
4. Comprimir/optimizar el PNG del logotipo si se necesita mejorar el rendimiento.

La familia tipográfica declarada es Liberation Sans con fallback a Arial/sans-serif. Los archivos de fuentes no se incluyen.
